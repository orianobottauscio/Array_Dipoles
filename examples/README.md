# Array Dipoles: two examples of input data for executing Array_Dipoles Matlab script. 

This folder contains two examples of input .toml files which enable two types of simulations: a deterministic one (det_case.toml) and a Montecarlo one (MC_case.toml).<br>
All additional input data are provided in the subfolders: PM_DATA, MATERIAL_DATA, TORQUE, and DSV.

The data of the magnet array, contained in subfolder PM_DATA are the one available on Open Source Imaging Initiative (OSI²) repository at the link:

https://gitlab.com/osii/magnet

To perform the simulations with the two examples, download the examples folder structure, open a command prompt in your local folder and execute the code as:

>Array_Dipoles det_case

or

>Array_Dipoles MC_case
